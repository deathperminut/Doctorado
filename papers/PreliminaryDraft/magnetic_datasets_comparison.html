📊 Datasets Experimentales de Dominios Magnéticos

Análisis comparativo para investigación en nanodots magnéticos

1. University of Leeds - Skyrmion Hall Angle Dataset
Utilidad: 65%
Técnica Experimental
STXM / MOKE Microscopy
Cantidad de Imágenes
~2,400 imágenes
Objetos Magnéticos
>1 millón skyrmions
Escala
35 - 825 nm (diámetros)
Tamaño Dataset
110 MB (dataset.zip)
Material
Ta/Pt/[Pt/CoB/Ir]×5/Pt
Parámetros Disponibles
Keff = 0.47 ± 0.04 MJ/m³ Skyrmion Hall angle = 9° ± 2° Diámetros medidos (35-825 nm) Velocidad = 6 ± 1 m/s DMI (D) - No reportado Exchange (J/A) - No reportado Ms - No reportado T - Ambiente (no variado)

Ventajas

  • Dataset GRANDE (2400+ imágenes)
  • Escala nanométrica adecuada (35-825 nm)
  • Sistema quiral con DMI implícito
  • Variabilidad en tamaños de skyrmions
  • Open access y bien documentado
  • Texturas magnéticas topológicas

Limitaciones

  • Solo Keff reportado explícitamente
  • Película continua, NO nanodots discretos
  • Un solo material (sin variación J, K, D)
  • No útil para problema inverso directo
  • Parámetros magnéticos incompletos
  • Temperatura no variada

🎯 Casos de Uso para tu Investigación

  • Transfer Learning: Preentrenar modelos para detectar texturas magnéticas quirales
  • Feature Extraction: Aprender representaciones de skyrmions para aplicar a nanodots
  • Validación Cualitativa: Comparar texturas generadas vs experimentales
  • Segmentación: Entrenar detectores de objetos magnéticos topológicos
  • NO usar para: Estimación de parámetros Hamiltonianos (problema inverso)
Enlaces:
📦 Dataset Repository 🔗 DOI: 10.5518/742 📄 Paper (Nature Comm 2019)
2. Co/Pd Multilayers - MFM Dataset
Utilidad: 60%
Técnica Experimental
MFM + AFM
Cantidad de Imágenes
~30-50 imágenes MFM
Tipo de Dominios
Stripe, labyrinthine, fragments
Escala
100 nm - 5 μm (dominios)
Año
2022
Material
Si/Ta/Pd/[Co/Pd]×50/Pd
Parámetros Disponibles
Keff - Varía con irradiación Aex - Varía con irradiación Ms - De hysteresis loops Coercitividad, Remanencia T - En simulaciones (300-1000K) Fluencia de iones (0.5-33×10¹⁴ cm⁻²) DMI - No significativo (Co/Pd)

Ventajas

  • Parámetros VARÍAN (Keff, Aex con irradiación)
  • MFM: técnica común para nanoestructuras
  • Incluye simulaciones micromagnéticas
  • Validación sim-exp integrada
  • Suplementarios descargables
  • Múltiples condiciones experimentales

Limitaciones

  • Película continua, NO nanodots
  • Sin DMI (sistema centrosimétrico)
  • Parámetros inferidos, no medidos directamente
  • Escala mayor (micras, no nanodots <100nm)
  • Dataset pequeño (~30-50 imágenes)
  • Solo 2 parámetros varían independientemente

🎯 Casos de Uso para tu Investigación

  • Domain Adaptation: Entrenar con simulaciones, adaptar a MFM experimental
  • Benchmark: Validar que modelos capturan dominios stripe/labyrinth
  • Metodología Híbrida: Aprender approach de combinar sim + exp
  • Validación de Texturas: Comparar dominios generados con MFM real
  • Limitado para Inverso: Solo Keff y Aex varían, no full Hamiltonian

3. KIT RADAR - Lorentz 4D-STEM Dataset
Utilidad: 40%
Técnica Experimental
4D-STEM Lorentz Microscopy
Tipo de Datos
Mapas cuantitativos + raw 4D
Resolución
<5 nm (nanométrica)
Escala
Nanométrica (strain + mag)
Año
2025 (Nature Comm - Feb)
Material
Ferromagneto amorfo deformado
Parámetros Disponibles
Campos magnéticos (Bx, By) - pixel-by-pixel Strain tensor - completo Estructura atómica - packing Correlaciones strain ↔ magnetismo Scripts MATLAB/Python J, K, D, Ms - No reportados T - No variado

Ventajas

  • Datos CUANTITATIVOS (campos magnéticos medidos)
  • Alta resolución (<5 nm)
  • Formatos procesables (HDF5, CSV)
  • Scripts de análisis incluidos
  • Paper muy reciente (Feb 2025)
  • Metodología transferible (4D-STEM → mapas)

Limitaciones

  • Material MUY diferente (amorfo ≠ cristalino)
  • Foco en strain, NO en J, K, D
  • Sin variación de parámetros Hamiltonianos
  • Geometría: película continua, NO nanodots
  • Física diferente (magnetoelástico vs DMI/exchange)
  • No aplicable a problema directo/inverso

🎯 Casos de Uso para tu Investigación

  • Aprender Técnicas: Reconstrucción de campos magnéticos desde TEM
  • Validación Metodológica: Comparar mapas simulados vs experimentales
  • Features Físicos: Entrenar con campos vectoriales (no solo intensidad)
  • Referencia Estado del Arte: Citar en marco teórico (técnicas avanzadas)
  • NO usar para: Entrenamiento directo (sistema muy diferente)

4. Experimental Exchange Interaction Dataset
Utilidad: 15%
Técnica Experimental
Inelastic Neutron Scattering (INS)
Tipo de Datos
Parámetros numéricos (NO imágenes)
Cantidad de Materiales
~100 materiales magnéticos
Escala
Bulk (cristales grandes)
Año
2025 (ArXiv/Nature Sci Data)
Formato
GitHub + Monte Carlo files
Parámetros Disponibles
J (exchange constants) - Heisenberg Tc (temperatura Curie) - calculado MC Estructura cristalina + pathways Spin wave dispersions Corrección cuántica (S+1)/S DMI - Explícitamente excluido Imágenes de dominios - NO incluidas

Ventajas

  • Parámetros J validados experimentalmente
  • Muchos materiales (~100 sistemas)
  • Formato Hamiltoniano unificado
  • Open access (GitHub)
  • Metodología bien documentada
  • Incluye simulaciones Monte Carlo

Limitaciones CRÍTICAS

  • SIN IMÁGENES: Solo parámetros numéricos
  • SIN DMI: Excluido intencionalmente
  • Escala bulk, NO nanodots
  • Spin waves en cristales grandes
  • No aplicable a modelos image-based
  • Física muy diferente a tu enfoque

🎯 Casos de Uso para tu Investigación

  • Referencias de J: Validar órdenes de magnitud en simulaciones
  • Contexto Teórico: Entender medición experimental de exchange
  • Comparación Metodológica: INS vs tus métodos image-based
  • NO usar para: Entrenamiento ML (sin imágenes)
  • NO usar para: Sistemas con DMI (excluido del dataset)

🎯 Recomendaciones de Uso

  1. Para Transfer Learning y Features: Usar Leeds Skyrmions (2400 imágenes, texturas quirales)
  2. Para Validación Sim-Exp: Usar Co/Pd MFM (variación de parámetros, metodología híbrida)
  3. Para Metodología Avanzada: Estudiar KIT 4D-STEM (reconstrucción cuantitativa)
  4. Para Contexto Teórico: Referenciar Exchange Dataset (valores de J validados)

⚠️ Nota Crítica: Ningún dataset cumple completamente con nanodots + parámetros Hamiltonianos variables. Se recomienda estrategia híbrida: entrenar con simulaciones (que tienes) + validar con estos datasets experimentales.
